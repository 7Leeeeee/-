# 我的课表（原生 iOS）

这是为单人使用设计的 SwiftUI 课表与学习任务 App。它不依赖学校账号或校园后端，课程通过截图生成的导入码进入 App；所有课表、作业、考试、DDL 和备忘均保存在设备本地。

## 当前范围

- 与截图一致的 14 节作息、分周课程、教师、教室与课程代码
- 今日课程、整周网格、教学周切换和周次过滤
- 作业、考试、待办、备忘四类任务
- 给任务指定开始/结束时间并叠加到周课表
- DDL 与独立提醒时间，本地通知在前台也显示横幅
- `MT1` 截图导入码：版本号、Base64URL 数据和 SHA-256 截断校验
- 下一节课、今日课表主屏幕小组件
- 当前/下一节课的锁屏实时活动与灵动岛
- App Group 本地共享，App 与小组件读取同一份数据
- 完全离线，无账号、无分析、无校园接口

## 当前截图识别结果

第一周按上海交通大学 2026–2027 秋季学期正式上课日设为 `2026-09-14`。初始数据包含：

- 周一：生物化学（1–8 周孙运彦；9–16 周阳怀宇）、宗教的社会人类学解释（1–12 周）
- 周三：生物统计学（1–11 周陈迎；12–16 周赵磊）
- 周四：生物化学、大学物理 B（一）、马克思主义基本原理
- 周五：体育与健康—网球（初）、生物化学实验

分周换教师会保存为独立课程记录，因此 App 能在对应周显示正确教师。

## 截图导入流程

1. 用户发送该学期每周的课表截图。
2. 根据截图合并相同课程，并保留调课、换教室、换教师和非连续周次。
3. 生成 `MT1.<数据>.<校验>` 导入码。
4. 在 App 的“设置 → 粘贴截图导入码”中粘贴。
5. App 先显示学期、第一周、节次数和课程数；确认后才替换课表，现有待办不会被删除。

## 不经过 App Store 安装

推荐使用 AltStore Classic：

1. 在 Windows 安装 Apple 官方版 iTunes、iCloud 和 AltServer。
2. 连接 iPhone，安装 AltStore，并在手机上开启“开发者模式”。
3. 从本项目的 GitHub Actions 下载 `MyTimetable-unsigned.ipa`。
4. 在 AltStore 中选择该 IPA，AltStore 会使用你的 Apple 账户重新签名并安装。
5. 免费账户签名有效期为 7 天；让 AltServer 与 iPhone 位于同一 Wi-Fi，可自动尝试刷新，也可在 AltStore 中手动刷新。

App 包含一个 Widget 扩展，因此会占用多个免费 App ID。小组件和灵动岛依赖 App Group；AltStore 支持带扩展和 App Group 的应用，但最终可用性仍取决于 Apple 当时签发的免费描述文件。

## 在 Mac 上构建

```sh
brew install xcodegen
xcodegen generate
open MyTimetable.xcodeproj
```

在 Xcode 中给 App 与 Widget 两个 target 选择同一个 Team，并确认两者的 App Group 都为 `group.com.personal.mytimetable`。

## 取舍说明

- 不接入校园系统、成绩、公告、食堂或图书馆服务。
- 不含账户、多账号、Face ID 锁和 Apple Watch。
- 作业、考试、DDL 与备忘统一为本地“学习任务”。
- 本地通知可自动弹出；没有推送服务器时，iOS 不保证在 App 被彻底结束后自动创建新的灵动岛实时活动，因此实时活动从“今天”页面开启。
